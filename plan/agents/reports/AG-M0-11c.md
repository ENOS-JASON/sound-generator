# AG-M0-11c — Replay and comparison handoff

**Status: PARTIAL — fixture scope, live integration pending.**

- Consumes recorder v1 from owner-authorized merged [PR #14](https://github.com/ENOS-JASON/sound-generator/pull/14), ADR-004 commands/events and telemetry v1. No change to shared contracts or ADR-001/006. Replay validates parsed local recorder data by reusing the bounded recorder and quantity registry; rejects incompatible schema, catalog and counters. Archive/checksum validation remains AG-M0-13.
- `ReplayController` exposes immutable tick-based telemetry playback, and explicit deterministic re-simulation against a freshly created compatible runtime. Commands are applied at their recorded tick/frame; incomplete traces, missing command frames, nonzero initial checkpoints and excessive endpoints fail. A caller-supplied observed end tick/frame is required because recorder v1 has no end checkpoint. Proposed local replay limits: 10 million frames, 100,000 simulation ticks, 65,536 event records. No raw imported audio playback.
- `ComparisonEngine` compares exact matching SI samples by stable channel ID and source clock; audio-frame comparison requires equal sample rates, quantity/basis/instrument compatibility is checked, missing samples/channels are explicit, and no interpolation is assumed. Returns signed B-A differences, maximum absolute/RMS difference, ordered event deltas by category-local sequence and simulated tick. Physical event comparison ignores playback-frame differences by default; exact replay can include frames. Comparable does not mean numerically equal or validated against real measurements.
- `tests/comparison.test.mjs` builds trace fixtures from merged seeded mock I4 and diagnostic pressure fixture, with scale/pause/manual step/resume. Tests exact state within 1e-12, domain/diagnostic events and clock, SI deltas at different playback rates, changed event payload, immutable playback, malformed schema/counters and incomplete capture.
