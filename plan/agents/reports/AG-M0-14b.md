**Status: partial, merged.** AG-M0-14a is merged, with the existing mock runtime, and AG-M0-11a/11d supply committed diagnostic/graph fixtures. ADR-001, upstream live integration and AG-M0-18 remain pending.

- Added expandable physics, audio and event panels plus a fixed registry of movable RPM and synthetic waveform widgets. The root shell mounts one widget board, independent of hash navigation. Pointer drag, keyboard arrows/Escape, individual hide, global hide/restore, viewport clamping and reset use a bounded versioned in-memory layout.
- RPM is a read-only derived-state graph from the existing GraphInspector and mock snapshot; the waveform is generated by the existing SyntheticStimulus fixture, not live AudioWorklet output. No producer or clock mutations, public contract changes or extra dependencies.
- Only visible widgets are sampled at a 100 ms interval; hidden widgets perform zero sampling. RPM graph history is capped at 64, projection at 32; waveform has 128 display points. The read counters expose the consumer work.
