# ADR-002 — Svelte UI major, hash router and state conventions

**Status: ACCEPTED — project-owner approval on 2026-11-18.** The project owner explicitly approved all four recommendations together in the current project conversation (response: “that is approved”). This is approval of the architectural decisions, **not evidence that PR #1 has merged**.

**Prior approved constraints:** Svelte + Vite, strict TypeScript (UD-R1-03) and static GitHub Pages hash URLs under `/sound-generator/#/...` (UD-R2-02). This ADR freezes the previously unresolved choices without revisiting those requirements.

## Accepted decisions

1. **Framework:** Svelte **5** + Vite **8**, with compatible pinned dependencies and a committed npm lockfile. Strict TypeScript remains mandatory.
2. **Routing:** initially a **lightweight hash router**, without an additional router dependency. Maintain typed, base-independent fragment links (`#/drive`, etc.). No browser-history routing. Expand only as justified by future cards; significant architecture changes return to the owner.
3. **Shared state:** use **built-in Svelte runes/stores**; do not introduce an external state-management library by default. Long-lived physics/audio runtime ownership remains independent of page navigation, with read-only UI projections. Exact shared service/API contracts remain the responsibility of their owning future agent cards, not invented here.
4. **UI component library:** **defer selection until necessary**. The initial semantic HTML shell requires no third-party component system. Any later major framework choice requires owner approval.

## Considered tradeoffs

- A minimal hash resolver has zero routing dependencies and supports GitHub Pages deep links/refresh, but it lacks a third-party router's nested/parameterized routes and lifecycle helpers. An external router can be proposed later if complexity justifies it.
- Built-in Svelte state reduces dependencies and preserves explicit runtime ownership; shared state and persistence require careful lifecycle tests in later task cards.
- Svelte 5 runes integrate with Vite 8; pinned versions and tests provide an explicit upgrade baseline.
