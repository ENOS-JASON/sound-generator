## Interaction and precedence rules

1. **Factory default vs autosave:** first launch (no valid saved choice) starts carbureted I4; a later valid explicitly user-saved/autosaved EFI choice must not silently be overwritten by the factory default. If prior data are corrupt/old, disclose recovery rather than guess.
2. **Quality metrics:** FPS is presentation frames/second only; engine state and audio work on independently scheduled physics and sample clocks. Audio rendering never waits on 2D/3D FPS.
3. **Acoustic independence:** user mixer faders, expert calibration trim, spatial listening position, and physical powertrain settings are distinct configuration domains with separate version/hashes and trace metadata. Neither expert trim nor perspective can change engine torque.
4. **Reference rights:** user-supplied real recording and distributable bundled measurement use **different provenance and authorization checks**. Real recordings remain **analysis-only, no playback anywhere**, even in reference comparison UI. Synthesized outputs may be recorded as diagnostics.
5. **Local compute:** GUI is a **separate local** frontend to versioned CLI/job control, not a remote worker cluster or browser backend. CPU/GPU remains optional, Windows and Linux are required targets, and resource logs/status survive restart where supported.
6. **AI review governance:** a dedicated AI agent may propose routine approval or merge only within explicitly granted GitHub permissions and documented rules; actual automatic merge authority, reviewer enforcement and escalation workflow are **pending owner/provider validation**. Do not create unapproved privileged tokens or claim configured branch protections.
7. **Model/measurement quality:** numerically converged models may be runnable without external measurements, but confidence/accuracy reporting discloses the absence. Any bundled reference data need proof of redistribution rights before inclusion.

## Required agent handoff

**Do not quietly add these features to unrelated existing cards.** [Roadmap](../08-implementation-roadmap.md), [task index](../agents/task-index.md) and phase work-order cards must each include individually reviewable tasks for **baseline presets; IndexedDB service; AI PR integrator; calibration profile control and editor; listening DSP and selector; local GUI monitor; licensed reference catalog**. All new work follows the approved PR, CI and gate policies. An unapproved engineering library or platform-specific integration remains `proposed / NON VALIDATED` until benchmark/prototype/approval.
