## Owner's required development hardware (additional mandatory constraint)

**Stated device:** **Intel Core i9, 10th generation (exact SKU unknown) + NVIDIA GeForce GTX 1080 (Pascal)**. This configuration **must be supported**, not treated as unsupported legacy-only hardware. Its exact RAM, OS, motherboard/driver and installed CUDA version are not known and must not be guessed.

- NVIDIA lists **GeForce GTX 1080 at CUDA compute capability 6.1 (`sm_61`)**: https://developer.nvidia.com/cuda/gpus/legacy
- NVIDIA explicitly documents that **CUDA Toolkit 13.0 removed offline compilation/library support for Pascal**, whereas **CUDA Toolkit 12.x (including 12.9) supports compiling Pascal kernels**: https://docs.nvidia.com/cuda/archive/13.0.0/cuda-toolkit-release-notes/ and https://docs.nvidia.com/cuda/archive/12.9.0/cuda-toolkit-release-notes/index.html
- NVIDIA's toolkit/driver matrix lists Pascal as `6.0/6.1` with **CUDA 12.x as the last supported toolkit family and driver R580 as last supported driver branch**: https://docs.nvidia.com/datacenter/tesla/drivers/latest/cuda-toolkit-driver-and-architecture-matrix.html
- **Required architecture:** versioned CUDA build target for `sm_61` compatible with **CUDA 12.x**, CPU multicore fallback, optional independently optimized modern-GPU backend, explicit capability/driver checks and informative degradation instead of silently pretending acceleration. Do not require tensor cores, `sm_75+` or CUDA 13-only SDK for a mandatory path; no unapproved forced hardware replacement.
- **Required smoke tests:** build and run a small `sm_61` CUDA numerical kernel; compare with CPU reference across boundary units/tolerances; report detected GPU/driver/toolkit, 44.1/48 kHz/browser compatibility separately and measured CPU/GPU execution time; test memory limits and missing/unsupported toolkit cases. **This is currently NOT VERIFIED ON THE USER'S MACHINE.**
- **Platform distinction:** owner's primary i9/GTX1080 machine is the **O3-01 real-time physics benchmark** and compatibility test target. **O3-05 defines a separate mid-range reference desktop configuration**, to be proposed by an agent and approved by the owner for the published 3D/2D FPS targets; the two machines may or may not coincide after explicit approval.
- **Numerical nuance:** physical accuracy/solver conservation takes precedence over GPU acceleration; tasks requiring unsupported precision or VRAM must run with honest CPU fallback, not fake successful CUDA support. Do not assume an NVIDIA GTX 1080 has tensor cores or modern GPU-only features.
